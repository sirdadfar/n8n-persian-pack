# سفارشی‌سازی

## ساختار یک ورک‌فلو

هر فایل سه بخش دارد:

```json
{
  "name": "۰۱ — سفارش ووکامرس → حسابداری → پیامک",
  "nodes": [ { "name": "...", "type": "n8n-nodes-base.httpRequest", "parameters": { } } ],
  "connections": { "گرهٔ الف": { "main": [[{ "node": "گرهٔ ب", "type": "main", "index": 0 }]] } }
}
```

قاعدهٔ طلایی: `connections` با **نام گره** کار می‌کند، نه شناسه. اگر نام گره‌ای را عوض کنید، باید همان نام در `connections` و در عبارات `$('نام گره')` هم عوض شود.

---

## تغییر پیامک به پنل دیگر

گرهٔ «پیامک» را باز کنید و فقط سه چیز را عوض کنید:

| پنل | آدرس | پارامتر شماره | پارامتر متن |
|---|---|---|---|
| کاوه‌نگار | `/v1/{KEY}/sms/send.json` | `receptor` | `message` |
| SMS.ir | `/v1/send/verify` یا `/v1/send/bulk` | `mobile` | `message` |
| ملی‌پیامک | `/apiv2/send` | `to` | `message` |

اگر پنل شما POST با بدنهٔ JSON می‌خواهد، در گره: `Method = POST`، `Send Body = true`، `Body Content Type = JSON` و بدنه را با `{{ JSON.stringify({...}) }}` بسازید.

---

## افزودن فیلتر روی ورک‌فلوی سبد رها شده

ورک‌فلوی ۰۲ الان هر سفارش `pending` را یادآوری می‌کند. اگر می‌خواهید فقط سفارش‌های بالای یک مبلغ را پیامک بزنید، در گرهٔ «قابل یادآوری است؟» یک شرط اضافه کنید:

```
{{ Number($json.total) }}  →  larger  →  500000
```

## تغییر کانال گزارش

گرهٔ «ارسال به تلگرام» را حذف/غیرفعال کنید و جای آن:

- **ایتا / بله / روبیکا**: گرهٔ HTTP Request به API همان پیام‌رسان
- **ایمیل**: گرهٔ `Send Email`
- **Google Sheets**: `Append Row` برای بایگانی گزارش‌ها

متن گزارش در گرهٔ «محاسبهٔ گزارش» ساخته می‌شود؛ فقط همان خروجی `text` را به کانال جدید بدهید.

## اضافه کردن ورک‌فلوی جدید به این بسته

1. تابع سازنده را در `scripts/build_workflows.py` اضافه کنید (از `node()` و `chain()` استفاده کنید)
2. فایل را به لیست `BUILDERS` اضافه کنید
3. اجرا کنید:

```bash
python3 scripts/build_workflows.py
npm run validate
```

اگر ورک‌فلو را در پنل n8n ساختید، از **Download** فایل JSON را بگیرید، در `workflows/` بگذارید و مطمئن شوید `"active": false` است و شناسهٔ گره‌ها یکتاست.

## نکات کارایی

- **Split In Batches** را برای هر API با محدودیت نرخ (rate limit) نگه دارید؛ ورک‌فلوی ۰۲ با دستهٔ ۵ تایی و ۲ ثانیه مکث کار می‌کند.
- برای حجم بالا، `per_page=100` و صفحه‌بندی با `after` بهتر از گرفتن همهٔ سفارش‌ها در یک درخواست است.
- در n8n، ذخیرهٔ تاریخچهٔ اجرا (`EXECUTIONS_DATA_PRUNE=true`) را روی سرورهای کوچک فعال کنید تا دیتابیس پر نشود.
