# بستهٔ اتوماسیون فارسی n8n

مجموعه‌ای از **۶ ورک‌فلوی آمادهٔ n8n** برای کارهای روزمرهٔ کسب‌وکارهای ایرانی: فروشگاه ووکامرس، حسابداری، CRM، پیامک و مانیتورینگ.

هدف این ریپو ساده است: هر کاری که در ایران واقعاً پول دارد و دستی انجام می‌شود، یک‌بار درست پیاده شود تا دیگران (و خودمان) دوباره از صفر نسازند.

> همهٔ ورک‌فلوها با `n8n import:workflow` و همچنین import از پنل، تست شده‌اند و از نظر ساختاری با `npm run validate` اعتبارسنجی می‌شوند.

## ورک‌فلوها

| فایل | کاری که می‌کند | سرویس‌های لازم |
|---|---|---|
| [`01-woocommerce-order-to-accounting.json`](workflows/01-woocommerce-order-to-accounting.json) | سفارش جدید ووکامرس → ثبت فاکتور در حسابداری → پیامک تأیید به مشتری → هشدار تلگرام در صورت خطا | ووکامرس، API حسابداری، کاوه‌نگار، تلگرام |
| [`02-abandoned-cart-reminder.json`](workflows/02-abandoned-cart-reminder.json) | پیدا کردن سفارش‌های «در انتظار پرداخت» و ارسال حداکثر یک پیامک یادآوری (با برچسب‌گذاری روی سفارش) | ووکامرس، کاوه‌نگار |
| [`03-daily-sales-report.json`](workflows/03-daily-sales-report.json) | هر شب ۲۱:۰۰ گزارش فروش روز را با پرفروش‌ها و میانگین سبد خرید به تلگرام می‌فرستد | ووکامرس، تلگرام |
| [`04-lead-to-crm.json`](workflows/04-lead-to-crm.json) | دریافت لید از فرم سایت → اعتبارسنجی شماره موبایل → ثبت در CRM → اعلان فوری به مدیر | CRM، تلگرام |
| [`05-invoice-ocr-to-accounting.json`](workflows/05-invoice-ocr-to-accounting.json) | عکس فاکتور → OCR → استخراج مبلغ/تاریخ/شماره → ثبت در دیتابیس → خلاصه در تلگرام | OCR، Postgres، تلگرام |
| [`06-site-uptime-alert.json`](workflows/06-site-uptime-alert.json) | هر ۵ دقیقه سایت را چک می‌کند و فقط در صورت تأیید قطعی (بررسی دوم) هشدار می‌دهد | تلگرام |

نکتهٔ مهم دربارهٔ ورک‌فلوی ۰۶: قبل از هشدار، سی ثانیه صبر می‌کند و دوباره چک می‌کند. بدون این کار، هر ری‌استارت کوتاه یک آلارم اشتباه می‌سازد و بعد از یک هفته کسی به هشدارها نگاه نمی‌کند.

## شروع سریع

### ۱) بالا آوردن n8n

```bash
docker compose up -d
# سپس http://localhost:5678
```

یا بدون داکر:

```bash
npm install -g n8n
n8n start
```

### ۲) تنظیم متغیرها

```bash
cp env.example .env
# مقادیر واقعی را جای‌گذاری کنید
```

متغیرها در n8n به‌صورت `{{ $env.NAME }}` در دسترس‌اند. اگر n8n را با داکر بالا می‌آورید، فایل `.env` را در `docker-compose.yml` به سرویس پاس بدهید (به‌صورت پیش‌فرض همین کار انجام شده).

### ۳) ایمپورت ورک‌فلو

از پنل: **Workflows → Import from File** و انتخاب فایل JSON.

یا از خط فرمان:

```bash
n8n import:workflow --input=workflows/01-woocommerce-order-to-accounting.json
```

### ۴) وصل کردن Credentialها

ورک‌فلوها بعد از ایمپورت **غیرفعال** هستند و Credential ندارند. تا وقتی دو مورد زیر را انجام ندهید اجرا نمی‌شوند:

1. Credentialهای تلگرام / ووکامرس / دیتابیس را از **Credentials → New** بسازید ([راهنمای فارسی](docs/credentials-fa.md)).
2. جای‌های خالی متغیرهای محیطی را پر کنید ([env.example](env.example)).

بعد برای هر گرهٔ Credentialدار، Credential ساخته‌شده را انتخاب کنید.

## اعتبارسنجی

```bash
npm run validate
```

این اسکریپت بدون نیاز به نصب n8n بررسی می‌کند که: JSON معتبر است، شناسهٔ گره‌ها یکتاست، نوع گره و نسخه تعریف شده، همهٔ اتصال‌ها به گره‌های موجود اشاره می‌کنند، گرهٔ یتیم وجود ندارد و ورک‌فلو به‌صورت پیش‌فرض فعال نیست. همین بررسی در GitHub Actions روی هر push اجرا می‌شود.

## بازسازی فایل‌های JSON

فایل‌های ورک‌فلو با اسکریپت زیر ساخته می‌شوند (برای اینکه شناسه‌ها یکتا و JSON تضمین‌شده معتبر باشد):

```bash
python3 scripts/build_workflows.py
```

اگر ورک‌فلویی را دستی در پنل n8n ویرایش کردید، تغییرات را در `scripts/build_workflows.py` هم اعمال کنید تا با اجرای دوباره از دست نرود.

## چه چیزهایی داخل این ریپو نیست

- توکن و رمز واقعی: هیچ کلیدی در ریپو وجود ندارد؛ همه از `$env` خوانده می‌شوند.
- کد اختصاصی کارفرما: این بسته مستقل و عمومی است.
- سرویس پیامکی خاص: الگوی کاوه‌نگار پیاده شده، اما با تغییر `KAVENEGAR_BASE_URL` و پارامترها می‌توانید هر پنل دیگری (فراز اس‌ام‌اس، ملی‌پیامک، ...) را وصل کنید.
